# KiqStat on X: captions, posting sequence and tagged links

Checklist item 4.4 · drafted 6 November 2026 · **for the founder to approve before anything is posted**

## What this is for

X has sent 16 signups and 1 payer in the whole life of the site (traffic report, 4.2). ChatGPT sent 40 signups and 8 payers. So X is not yet a buying channel; this pack is a two-week test of whether a steady, honest account can change that, with every link tagged so the result is measured and not guessed (4.5 reads it at 48 hours and 7 days).

It is deliberately modest: one post a day, no giveaways, no claims we cannot show on the Track page.

## Rules every post follows

1. **No promise of winning.** KiqStat shows the chance a model puts on a result, not a certain outcome. Say "chance", "model", "price", never "sure", "banker" or "lock".
2. **No bookmaker names in copy.** Say "booking code". (The product itself supports SportyBet codes; the posts do not name them.)
3. **18+ and responsible use** on any post that shows picks or codes. Link `/responsible-use` in the pinned post and the bio.
4. **Numbers only from the Track page** on the day of posting, screenshot attached. Never a remembered or rounded-up figure.
5. **No post about a specific match result after it ends** unless it is on the Track page (no cherry-picking winners).
6. Nigerian advertising and gambling-promotion rules apply to betting content. The founder confirms these captions meet them before the first post; I have not checked the regulator's current wording.

## Tagged links

Every link back to the site carries `utm_source=x`. First-touch capture stores it on the signup, and Admin → Traffic → KiqStat signups shows it as `x / <medium>` next to what that source paid.

Pattern: `https://www.kiqstat.app/<page>?utm_source=x&utm_medium=<medium>&utm_campaign=nov26-test&utm_content=<post id>`

| Medium | Where it is used |
|---|---|
| `bio` | link in the X profile (one fixed link, never changes) |
| `pinned` | the pinned post |
| `post` | an ordinary daily post |
| `thread` | links inside a thread |
| `reply` | a link dropped in a reply to someone else |

Campaign is `nov26-test` for the whole two weeks so 4.5 can total the test; `utm_content` is the post ID below (P1 to P14) so each post can be compared.

The site's `utmUrl()` helper (`src/lib/utm.ts`) builds the same links in code; for X posts they are pasted by hand.

## Tagged-link bookkeeping

- The bio link is `utm_medium=bio&utm_content=profile`; set once.
- A post's link is made the same way every time; no shortening service in between (a shortener hides the referrer and the tags can be stripped).
- X wraps links in `t.co`. The tag still arrives; Traffic will show these as `x / post`, `x / pinned`, etc., separate from the untagged `t.co` row (those are earlier, untagged links).
- Do not tag links to anywhere other than our own site.
