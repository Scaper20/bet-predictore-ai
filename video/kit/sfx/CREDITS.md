# SFX palette

The effects the KiqStat films use, copied into every project by `kiqstat_video.prepare()`.

| File | Source | Use |
| --- | --- | --- |
| click.mp3, key-press.mp3, pop.mp3, riser.mp3, whoosh.mp3 | HyperFrames media-use bundled set, from [Pixabay](https://pixabay.com/sound-effects/) under the [Pixabay Content License](https://pixabay.com/service/license-summary/) (commercial use, no attribution needed) | taps, ticks per item, badges, the build into the payoff, short moves |
| boom-low, click-sharp, impact-bass, pop-hollow, thud-muffled, whoosh-airy, whoosh-quick, whoosh-synth (.mp3) | HeyGen sound catalog (`heygen audio sounds list --type sound_effects`), downloaded for KiqStat's own videos | reveal slam, tab and button clicks, the logo ball, messages, a lost leg, scrolls and floods |

Peak times (seconds into each file) used to place them, from the Code Hub ad: boom-low 0.080,
click-sharp 0.125, click 0.073, impact-bass 0.073, key-press 0.076, pop-hollow 0.160, pop 0.120,
riser 3.472, thud-muffled 0.070, whoosh-airy 0.450, whoosh-quick 0.215, whoosh-synth 0.345, whoosh 0.162.
